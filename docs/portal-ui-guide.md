# Realty Adwise Portal UI Guide

## Admin UI

### Dashboard

The Admin dashboard shows overall lead activity, pending assignments, properties needing executives, and recent activity.

### Leads

Admin can view all leads, filter and search them, open lead details, update statuses, assign or reassign executives, transfer leads, and split enquiries.

### Customers

Admin can search customers, open customer profiles, view their lead history, and update customer details.

### Properties

Admin can create and edit properties, activate or deactivate them, select the executives assigned to each property, and view assignment history.

### Managers

Admin can create, edit, activate/deactivate, reset passwords for, and delete managers.

### Executives

Admin can create, edit, activate/deactivate, reset passwords for, delete executives, and assign executives to managers.

### Settings

Admin can configure the lead assignment rule and the lead response-time timeout.

## Manager UI

### Dashboard

The Manager dashboard shows team leads, pending leads, important leads, and the number of active executives reporting to the manager.

### Leads

Managers can view their team’s leads, search and filter them, create new leads, assign pending leads, update statuses, transfer leads, and split enquiries.

### Lead Details

The lead detail screen shows customer information, property information, assignment details, status, SLA timer, follow-ups, notes, customer history, and WhatsApp actions.

### Executives

Managers can view the executives assigned to them and access each executive’s lead view.

## Executive UI

### My Leads

The Executive dashboard shows only leads assigned to that executive. Leads can be searched and filtered by status, source, importance, and follow-up.

### Lead Details

Executives can view customer and property details, update the lead status, mark the lead as important, add follow-ups and notes, call the customer, and open WhatsApp.

## Common UI Features

- Realtime notifications for new leads, assignments, status changes, and SLA warnings.
- Responsive layouts for desktop and mobile screens.
- WhatsApp actions for copying or sharing CRM messages.
- Automatic refresh of lead and dashboard information.
- Role-based navigation: each user sees only the screens available to their role.
